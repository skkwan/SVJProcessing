# README

These are scripts used to perform the virtual environment setup in lxplus. They are modified slightly from [these instructions](https://github.com/jniedzie/SVJanalysis_wiki/wiki/Creating-SVJ-virtual-environment) to replace `mamba` calls with `conda`. 

Following the linked instructions, we just run, in EOS,
```bash
source makeSVJEnv.sh
```

Then to activate the venv:
```bash
activate svj
```
